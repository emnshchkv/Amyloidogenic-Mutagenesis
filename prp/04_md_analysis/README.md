## Description of the process
In this final computational phase, atomistic Molecular Dynamics (MD) simulations are applied to evaluate the conformational stability and structural transitions of the Wild-Type (WT) Prion Protein versus selected "breaker" mutant (V180R).

While static tools (PASTA 2.0, TANGO, etc.) predict amyloidogenic propensities based on sequence alone, MD simulations reveal time-dependent structural mechanics at atomic resolution. The analysis focuses heavily on residues 170-193, a critical region implicated in pathological scrapie (PrP^Sc) conversion. By tracking global stability metrics (RMSD, Rg) alongside local dynamics (DSSP, intramolecular hydrogen bonds, and Helix 2–Helix 3 contact interfaces), we verify whether prioritizing mutations via the integrative Z-score translates to physical destabilization of the amyloidogenic seed.

## Cautions needed to be highlighted
* Topology Atom Mismatch: Do not load raw AlphaFold3 PDB structures directly as topologies for GROMACS trajectories. GROMACS alters protonation states and caps terminal groups (adding/removing atoms). Always use a structure generated by GROMACS (e.g., extracted via `gmx trjconv` from a `.tpr` file) to match the `.xtc` atom count exactly.

* Residue Numbering Offset: AlphaFold3 outputs typically index residues starting at 1. In standard biological literature, mature PrP cores start at residue 23 (post-signal peptide cleavage) or residue 125 (for truncated C-terminal constructs). Set the RESIDUE_OFFSET (22 or 124) in the configuration block to shift the coordinates in-place. This ensures selectors like resid 170:193 accurately clip the target region.
