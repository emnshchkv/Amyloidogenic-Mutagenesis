# Results Directory Structure

The `results/` directory serves as the primary output and analysis storage location for molecular dynamics (MD) simulation data and subsequent analytical workflows. It contains processed trajectory files, topology files, and Jupyter notebooks used for the analysis of wild-type (WT) and mutant amyloidogenic proteins (primarily Aβ and PrP variants).

## Detailed Description of Contents

### 1. `XTCs_and_TPRs/NO_SOL/`

This subdirectory stores **GROMACS** simulation output files for **protein-only** systems without solvent (hence the `NO_SOL` designation). These files were generated after post-processing steps such as centering, fitting, and solvent removal from full-system MD trajectories.

- **`.tpr` files** (GROMACS portable run input files):
  - `protein_only_WT.tpr` — Topology and run parameters for the wild-type protein.
  - `protein_only_G25D.tpr` — Topology and run parameters for the G25D mutant.
  - `protein_only_solo_WT.tpr` and `protein_only_solo_G25D.tpr` — Variants representing single-chain (monomeric) simulation setups.

- **`.xtc` files** (GROMACS compressed trajectory files):
  - Contain the atomic coordinates over the simulation time for the respective systems and are used for downstream structural and dynamic analyses.

- **`.npz` offset files**:
  - Auxiliary index/offset files generated by MD analysis libraries (e.g., `MDAnalysis`) to enable fast random access to trajectory frames.

**Important note regarding tetramer trajectories**:  
The full `.xtc` trajectory files for the tetramer models could not be uploaded to the repository due to GitHub's maximum allowable file size limit. However, these large trajectory files can be obtained by following the instructions provided in the `MD/MD_tetramers/` directory.

### 2. `notebooks/`

Contains **Jupyter notebooks** for reproducible data analysis:

- **`Monomers_analysis.ipynb`** — Analysis of monomeric forms of the proteins, including structural metrics, solvent-accessible surface area (SASA), radius of gyration, secondary structure evolution, and mutation-induced conformational changes.

- **`Tetramers_analysis.ipynb`** — Analysis of oligomeric (tetrameric) assemblies, focusing on inter-chain interactions, β-sheet formation, aggregate stability, and the effect of mutations on oligomerization propensity.
